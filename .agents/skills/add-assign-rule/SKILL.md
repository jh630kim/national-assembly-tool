# 배분규칙 보강

## 1. 언제 쓰는지
- `data/배분기준표_소관키워드_304건.csv`의 배분 정확도를 시험 문항과 과거 접수대장으로 확인하고, 규칙 보강을 요청받았을 때 사용한다.
- 입력은 배분기준표, `data/A부_조직도_26개과.csv`, `data/시험_요구문항_40건.csv`, 읽기 전용 `data/요구자료_접수대장_2026국감_520건.csv`와 현재 엔진이다.

## 2. 순서
1. 현재 엔진으로 시험 40건과 접수대장 520건의 1순위 결과를 원자료 정답과 대조하고, 틀린 문항의 점수·근거키워드를 확인해 원인별로 묶는다.
2. 원인마다 제외어 추가·키워드 추가·우선순위 변경 중 근거 있는 방법 하나를 제안한다. 새 소관 과는 조직도 26개 과에 있는 경우에만 제안한다. 사본을 만들기 전에 제안별 전후 정확도와 새 오답을 메모리에서 확인한다.
3. 사용자가 고른 방법만 `rules_보강.csv`에 반영한다. 원본 기준표와 접수대장은 수정하지 않고, 바꾼 규칙 ID·기존 값·새 값을 확인한다.
4. 실제 사본으로 엔진을 다시 실행해 시험 40건과 접수대장 520건의 1순위 정답 수를 전후 표로 비교한다. 시험에서 새로 틀린 문항 수와 바뀐 문항도 확인한다.
5. 변경 이유, 바꾼 규칙, 전후 결과와 남은 오답을 `PROGRESS.md`에 기록한다.

## 3. 끝나는 조건
- 시험 40건의 1순위 정답이 30건 이상이고, 기존 정답이 새 오답으로 바뀐 시험 문항이 0건이다.
- 전후 표의 분모가 원자료의 40건·520건과 일치하고, 사본에서 사용자가 고른 규칙만 바뀌었다.

## 4. 하지 말 것
- 사용자 선택 전이나 선택하지 않은 수정안을 기준표 사본에 적용하지 않는다.
- 원본 기준표·과거 접수대장을 고치거나 조직도에 없는 과를 만들지 않는다.
- 시험 점수만 높이려고 원문 근거가 없는 규칙을 추가하거나 동순위·불일치를 자동 확정하지 않는다.
