# 자료요구서 문항 분리

## 절차
1. 프로젝트의 `PROGRESS.md`, `CONTEXT.md`, `처리지침.md` 제2장과 `원문/`의 PDF를 읽는다. 기존 `split.py`와 교체된 `data/문항목록.csv`가 있으면 함께 대조한다. `99_완성본_잠금`은 열지 않는다.
2. 프로젝트 `.venv`에 `pypdf`가 있는지 먼저 확인한다. 없으면 `pip install pypdf`를 보여 주고 사용자 허락을 받은 뒤 설치한다.
3. PDF 첫 줄의 `○○위원회 ○○ 의원실 자료요구서`에서 위원회와 의원을 읽고, `수신: … 제출기한: YYYY. M. D.(요일) HH:MM까지` 줄에서 날짜를 `YYYY-MM-DD`로 바꾼다. `수신:`, `담당 보좌관:`, `끝.` 줄은 문항에 넣지 않고 이름·연락처를 저장하지 않는다.
4. 줄 맨 앞의 `숫자.`는 새 문항이다. `가.`·`나.` 등은 앞 문항의 세부항목, `※`는 앞 문항의 비고다. 그 밖의 줄은 바로 앞 항목에 잇는다. 세부항목은 표기를 보존해 ` / `로 잇고, 비고는 앞의 `※`만 제거한다.
5. 프로젝트 루트의 `split.py`를 만들거나 필요한 부분만 수정한다. `pypdf`와 Python 표준 라이브러리만 사용한다. 출력은 `data/문항목록.csv`, UTF-8-SIG, 열 순서는 `파일명 | 위원회 | 의원 | 제출기한 | 문항번호 | 요구내용 | 세부항목 | 비고`다. 기존 PDF와 `data/` 파일은 보존한다. 교체된 문항목록이 있으면 이를 덮어쓰지 않고 추출 결과와 비교한다.

## 확인
- 파일별로 `파일명 | 파일명의 문항 수 | 뽑은 문항 수 | 마지막 번호 | 번호 연속 | 일치(O/X)` 표를 제시한다. 파일명에 문항 수가 없는 경우에는 원문에서 확인한 수를 사용하고 근거를 밝힌다.
- 세부항목과 비고가 있는 문항 3개를 원문 PDF 내용과 추출 결과가 나란히 보이도록 제시한다. 가능하면 PDF별로 하나씩 고른다.
- 교체된 문항목록 CSV가 있으면 행 수·열 순서·모든 셀을 비교하고 차이 건수를 보고한다. 보좌관 이름·연락처가 출력에 없는지도 확인한다.
- 일치가 `X`이거나 교체된 CSV와 차이가 나면 원문과 분리 규칙을 대조해 원인을 고친 뒤 다시 실행한다. 원문만으로 결정할 수 없는 차이는 임의로 맞추지 않고 확인이 필요한 항목으로 보고한다.
